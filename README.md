# Calculator Swift

A simple console calculator written in Swift.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero validation
- User input handling

## Technologies

- Swift
- Foundation

## How it works

The calculator asks the user to enter two numbers and choose an arithmetic operation.

Example:

```text
=== КАЛЬКУЛЯТОР ===

Введите первое число:
10

Введите операцию (+, -, *, /):
+

Введите второе число:
5

Результат: 15.0
